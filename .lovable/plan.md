

# Create Two Test Cycles from Document Upload QA Document

## Document Analysis

The uploaded document covers the **Document Upload Feature** end-to-end QA with **4 groups and 19 scenarios total**:

| Group | Focus | Scenarios |
|-------|-------|-----------|
| A | Upload and Full Extraction Verification | A1–A7 (7) |
| B | Negative and Edge Case Uploads | B1–B5 (5) |
| C | Publish, Share, and Batch Assignment | C1–C3 (3) |
| D | Student Panel and Test Attempt | D1–D4 (4) |

## Proposed Split

### CYC-004: PDF Upload and Content Quality QA
**Groups A + B = 12 scenarios**

Covers the Super Admin upload workflow: extracting questions from real exam papers (JEE, FIITJEE, Allen, Akash, PW), verifying question counts, subject grouping, math rendering, image loading, AI-generated solutions, tagging — plus negative cases (non-question docs, password-protected PDFs, scanned PDFs, unsupported formats, duplicate uploads).

**Testing Guide** will include:
- "What Is This Feature?" context
- "Where to Get Test Documents" reference table (JEE, FIITJEE, Allen, Akash, PW sources)
- "How Testing Is Organized" overview
- Bug reporting instructions
- Group A and B descriptions

### CYC-005: Exam Lifecycle and Student Experience QA
**Groups C + D = 7 scenarios**

Covers the downstream workflow after upload: publishing papers, sharing with institutes, batch assignment, institute isolation — then the student experience: starting tests, navigating questions, selecting answers, marking for review, submitting, viewing results/solutions, and time window enforcement.

**Testing Guide** will include:
- Context linking back to CYC-004 (upload must be done first)
- Cross-reference to Groups A/B for prerequisite understanding
- Group C and D descriptions
- Scenario summary tracking table

## Implementation

Three sequential database inserts per cycle (same pattern as CYC-001/002/003):

1. **Insert `test_cycles`** — two rows with full HTML Testing Guide descriptions
2. **Insert `cycle_groups`** — 4 groups total (2 per cycle: A+B in CYC-004, C+D in CYC-005) — but using new letter codes (H, I, J, K) to avoid collision with CYC-003's D/E/F/G groups
3. **Insert `cycle_scenarios`** — 19 total (12 + 7) with titles, descriptions, and step-based verification extracted from the document

The `cycle_code` values (CYC-004, CYC-005) will be auto-generated by the existing `generate_cycle_code()` trigger.

**No code changes required** — backend data insertion only.
