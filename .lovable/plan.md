

# Create Test Cycle: Course Assignment & Scope QA

## Overview
Insert a new test cycle from the uploaded document, same approach as CYC-001 and CYC-002 — backend data insertion only.

## Data to Insert

### 1. Test Cycle (test_cycles)
- **Name:** Course Assignment & Scope QA — Does the Course Reach the Right People and Batches?
- **Priority:** critical
- **Status:** active
- **project_id:** `11111111-1111-1111-1111-111111111111`
- **created_by:** `88326c88-1370-4d30-8eeb-e05941e74931`
- **description:** Full HTML conversion of the markdown — includes Assignment-Specific Terms glossary table, Course Flow ASCII diagram, Filtering Logic diagram, Quick Reference Matrix tables, Filtering Rules Quick Check table, Known Bug Patterns section, Cross-References section, and Summary.

### 2. Cycle Groups (cycle_groups) — 4 groups

| Group | Name | Scenarios |
|-------|------|-----------|
| D | Batch Creation with Courses (Institute) | D1–D7 (7 scenarios) |
| E | Exam Assignment Filtering | E1–E7 (7 scenarios) |
| F | Teacher Scope with Courses | F1–F7 (7 scenarios) |
| G | Institute Question Bank Isolation | G1–G3 (3 scenarios) |

### 3. Cycle Scenarios (cycle_scenarios) — 24 total
Each scenario extracted with title, description, and step-based verification from the document. Scenario codes follow the document's labeling (D1–D7, E1–E7, F1–F7, G1–G3).

## Implementation
Three sequential SQL inserts:
1. Insert `test_cycles` row with full HTML description
2. Insert 4 `cycle_groups` rows
3. Insert 24 `cycle_scenarios` rows mapped to their respective groups

The `cycle_code` (CYC-003) will be auto-generated by the `generate_cycle_code()` trigger.
