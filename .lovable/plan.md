## Implementation
Three sequential SQL inserts using the insert tool:
1. Insert `test_cycles` row with full HTML description (converted from markdown with tables, code blocks, glossary)
2. Insert 3 `cycle_groups` rows
3. Insert 27 `cycle_scenarios` rows mapped to their respective groups

The cycle_code (CYC-002) will be auto-generated by the existing `generate_cycle_code()` trigger.
